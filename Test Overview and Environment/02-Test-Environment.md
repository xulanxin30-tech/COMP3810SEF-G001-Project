# Test Environment

We ran the tests on a Windows laptop with Node.js v22.22.2 and npm 10.9.7. The app uses Express 5, EJS 7 and Mongoose 9, installed with `npm install` (123 packages). For the database we used an in-memory MongoDB started with mongodb-memory-server on port 27019, with a test database called g001test. This goes through the same Mongoose code as a real MongoDB but needs nobody's personal connection string and leaves no data behind. We started the server with `PORT=3111` to avoid clashing with other services, seeded 3 users and 3 books with `npm run seed`, and sent all requests with curl from Git Bash. Logged-in cases kept their cookies in a jar file. The README asks for deployment on an Ubuntu VM with Firefox at port 3000; we did not provision a new VM for this pass, but the routes, status codes, cookies and JSON bodies are all the same. For the presentation the group can still follow the README and use the VM IP instead of localhost.

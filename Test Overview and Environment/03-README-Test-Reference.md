# README Reference

Everything we tested comes from the README on the main branch. We followed its operation guide to install packages, set the environment variables, seed the database and start the server. We used the seeded account s0000001 / sz212345 to log in, then checked the dashboard, the book list with its three books, search by title, add a book and edit a book. We also ran the four curl commands for /api/items; they work once the example ID is replaced with a real one. The README says book pages need login, and that is true — without a cookie we were redirected to /auth/login. Two small gaps between the README and the code: the login form does not submit the `next` parameter even though the route reads it, so login always ends at the dashboard; and the curl examples show an 18-character ID while MongoDB IDs are 24 characters, so those commands return 404 exactly as printed.

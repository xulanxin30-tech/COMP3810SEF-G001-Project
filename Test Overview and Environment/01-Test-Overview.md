# Test Overview

This is the final test for the COMP3810SEF Group G001 project. The course is about server-side technologies and cloud computing, so our project is a server application running on a virtual machine and reached over the network. The README on the main branch is our main reference — we took the setup steps, routes, seeded accounts and curl commands from it. The project brief in the PDF also asks for a working server-side application and a demo, so most of our tests are HTTP requests sent to the running server. We checked setup and seed data, login and logout, the book pages (list, add, edit, delete, search), the /api/items API, access control for logged-in users, and how the app handles bad input. We did not do load testing or browser compatibility checks. All the normal flows in the README passed; the problems we found are in error handling and session setup, and they are written up in the other folders.
